# Real phone checklist

Playwright covers reload and a faked clock jump. It does not cover a locked phone or a home-screen install. Record the date and pass/fail here without personal data when the devices are available.

- [ ] iOS home screen, standalone, login
- [ ] Android home screen, standalone, login
- [ ] Diaper entry on a phone-sized screen
- [ ] Timer started, phone locked for several minutes, elapsed time still correct
- [ ] Timer still correct after the app is force-closed
- [ ] Side switch from a second device
- [ ] Failed save shows Not saved
- [ ] After logout, the timeline is not served from the service worker
